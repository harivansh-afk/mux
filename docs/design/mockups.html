Chips are sessions - the numbers are the same prefix 1-9 that already exists. Active · running (pulsing yellow) · finished-since-last-look (green) · bell / exit≠0 (red) · idle (nothing). While the prefix is held they gain a few words inline, never growing taller. Data is OSC 133 marks + terminal titles via muxd.

Interaction layers

Ambient  always on  ·  color + geometry only, never text  ·  spines, dots, ticks
Glance  hold prefix  ·  one-line tags + inline chip status  ·  release to dismiss
Command  modal  ·  canvas (panes), hosts, palette  ·  full detail, full control

The contract: the default view never gains a new persistent element. New capability lands in glance, in canvas, or in the palette - so the terminal stays a terminal.
